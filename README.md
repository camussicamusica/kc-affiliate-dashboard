# KC Affiliate Research Desk

A static, public-safe dashboard for KC and Sofia. Open `index.html` locally, or publish the three site files with GitHub Pages. Every answer card has a **Read the full answer** row with a plus sign; click or press Enter/Space to open it. It uses no framework, build step, credentials, analytics, or account connection.

## Publish with GitHub Pages

1. Create a repository containing only `index.html`, `styles.css`, `script.js`, and this README. **Do not upload the surrounding second-brain folder**, which contains private research and account context.
2. In the repository, open **Settings → Pages** and set **Build and deployment** to **Deploy from a branch**. Choose the branch containing the files and the `/ (root)` folder.
3. Use the Pages URL GitHub shows after deployment. Repository and Pages visibility depend on your GitHub settings.

## Update later

- Edit the short answers and their `<details class="answer-detail">` sections in `index.html`. Change the visible verification date when the underlying facts are rechecked.
- Keep counts in the filter buttons aligned with the card `data-category` values (`act`, `verify`, `later`).
- Replace any account observations only after checking current Amazon, ViralVue, and Meta views. This site does **not** update automatically.
- Keep account IDs, email addresses, screenshots, campaign-specific private data, and group discussions in the shared second brain. The detailed source remains `../2026-10-14-affiliate-research-findings.md` in the local Drive workspace.
